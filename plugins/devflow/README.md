# devflow

A Claude Code plugin that runs a disciplined AI engineering workflow with human approval checkpoints:

**Analyze (clarifying questions) → Design (acceptance criteria) → Implement (test-first) → Review → Verify (Playwright evidence) → Ship (PR)**

See the repository root README for installation and usage.

## Install

```
/plugin marketplace add your-user/devflow-tools
/plugin install devflow@devflow-tools
```
